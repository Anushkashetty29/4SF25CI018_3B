# Spotify Dataset Analysis

## Objective
To analyze a Spotify dataset using Python and Pandas, perform data transformations, handle missing values using mean imputation, generate meaningful insights, and visualize the findings.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Steps
1. Dataset Selection and Reading
2. Data Understanding
3. Data Transformation
4. Handling Missing Values
5. Insight Generation
6. Data Visualization

- Spotify_Data_Analysis.ipynb
- dataset.csv
